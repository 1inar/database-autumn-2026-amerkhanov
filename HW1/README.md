# Запросы к БД "Платформа для поэтов"

## Запрос 1 (Выборка + Проекция)
**Формулировка:** Найти названия и даты публикации всех стихотворений, опубликованных после 1 января 2024 года.
**Реляционная алгебра:**
π(Название, Дата_Публикации) (σ(Дата_Публикации > '2024-01-01') (Стихотворение))

## Запрос 2 (Соединение)
**Формулировка:** Вывести имена авторов и названия их стихотворений, которые получили оценку 5 баллов.
**Реляционная алгебра:**
π(Имя, Название) (Пользователь ⋈(Пользователь.ID = Стихотворение.ID_Автора) (Стихотворение ⋈(Стихотворение.ID = Оценка.ID_Стихотворения) σ(Балл = 5) (Оценка)))

## Запрос 3 (Выборка + Соединение)
**Формулировка:** Вывести названия стихотворений и имена их авторов, чей email заканчивается на @mail.ru.
**Реляционная алгебра:**
π(Название, Имя) (Стихотворение ⋈(Стихотворение.ID_Автора = Пользователь.ID) σ(Email LIKE '%@mail.ru') (Пользователь))

## Запрос 4 (Соединение M:M)
**Формулировка:** Найти названия всех стихотворений, относящихся к жанру «Лирика».
**Реляционная алгебра:**
π(Название) (Стихотворение ⋈(Стихотворение.ID = Стих_Жанр.ID_Стихотворения) (Стих_Жанр ⋈(Стих_Жанр.ID_Жанра = Жанр.ID) σ(Название_Жанра = 'Лирика') (Жанр)))

## Запрос 5 (Агрегация)
**Формулировка:** Вывести имена пользователей и их средний балл, для тех, у кого средний балл выше 4.
**Реляционная алгебра:**
π(Имя, Средний_Балл) (σ(Средний_Балл > 4) (Имя G AVG(Балл) → Средний_Балл (Пользователь ⋈(Пользователь.ID = Оценка.ID_Пользователя) Оценка)))
