# Платформа для поэтов
## Описание предметной области

Проект представляет собой базу данных для онлайн-платформы, где поэты могут публиковать свои стихи, а читатели -- читать, оценивать и комментировать их. Предметная область охватывает учет пользователей, публикации произведений, а также взаимодействие аудитории с контентом

№№ Проблема: 
На стандартных социальных платформах сложно структурировать поэтический контент по жанрам и формам, а также отслеживать статистику популярности конкретных авторов и стихотворений. Данная БД решает задачи каталогизации стихов, управляя комментариями, оценки произведений и формирование рейтингов поэтов.
